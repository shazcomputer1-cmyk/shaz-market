# SHAZ MARKET

وەشانی نوێی دیزاینی SHAZ MARKET، بە HTML/CSS/JavaScript و RTL بۆ کوردی.

## تاقیکردنەوە
- `index.html` لە browser بکەرەوە.
- بۆ ئەوەی Supabase کار بکات، `config.js` پێویستە و RLS policies ـی دروست لە Supabase پێویستە.
- ئەم وەشانە هێشتا بە شێوەی خۆکار بڵاونەکراوەتەوە؛ بۆ لینکێکی گشتی پێویستە لە Netlify/Vercel یان هاوشێوە deploy بکرێت.
- کلیلێکی `service_role` یان نهێنی لە `config.js` مەخە؛ تەنها publishable/anon key بەکاربهێنە.
