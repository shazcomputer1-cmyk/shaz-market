# SHAZ MARKET — Social links update

This package contains the existing six website files, with TikTok, Instagram, Facebook, and YouTube links added to the footer.

## Files
- index.html
- style.css
- app.js
- config.js
- hero-reference.png
- README-KU.md

## Important
This ZIP updates the website files but does not itself deploy them to Cloudflare. Do not paste HTML into the Cloudflare Worker JavaScript editor. The deployed Worker needs to be connected to these static assets using a supported assets deployment workflow.
